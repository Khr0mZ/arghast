# Mapa localizador de Archi

Prototipo para localizar portadores de piedras vinculadas.

Revisión narrativa hasta el capítulo 123.

Identidad del bloque Kuroto; grafías y alias pendientes de contraste, sin fusión automática.

## Ingenios y urgencias antes del banquete

Archi desarrolla este mapa con runas, cristal y piedras que deberían indicar la posición y el estado de los soldados. Al mostrarlo solo funciona con una piedra. Calista propone negociar recursos para ampliarlo, pero el inventor conserva el prototipo; no se muestra un sistema desplegado para el ejército.
